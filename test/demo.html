Silicon Notes Demo Playground

Test the full capability of the extension directly on this page: rich text editing, dragging, resizing, color switching, collapsing, and multi-tab persistence.

Getting Started

How to Test this Chrome Extension

  1. Open Chrome and navigate to chrome://extensions
  2. Enable Developer mode in the top-right corner.
  3. Click Load unpacked and select this folder (silicon_notes).
  4. Open this demo page (or any webpage on the internet).
  5. Click the extension icon in the toolbar or press Alt+Shift+N (Mac: Cmd+Shift+N) to spawn a new sticky note!

Feature Verification Checklist

  • Drag & Viewport Bounds: Drag any note by its top header bar. Notice smooth motion and viewport clamping so it cannot be dragged off-screen.
  • Rich Text Formatting: Select text in the note and use the toolbar or shortcuts: Ctrl+B (Bold), Ctrl+I (Italic), Ctrl+U (Underline), Strikethrough, Bulleted Lists, Numbered Lists, and Inline Code.
  • Active State Reflection: Notice how toolbar buttons highlight when your caret moves into bold, italic, or list items.
  • Focus Preservation: Clicking toolbar buttons never collapses your selection in the note.
  • Color Themes: Click the palette icon in the header to switch between 4 WCAG-compliant pastel themes (Yellow, Mint Green, Sky Blue, Rose Pink).
  • Collapse / Expand: Click the minus button (–) in the header to fold the note down to just its title.
  • Corner Resizing: Drag the bottom-right corner to resize. Custom dimensions are saved!
  • Shadow DOM Isolation: Webpage stylesheets and resets never bleed into the sticky notes.
  • Persistence: Refresh the page or close and re-open Chrome. Your notes stay exactly where you placed them!
